# Google Pay Expense Sharing Application

A Python-based web application to track, split, and manage expenses among multiple users.

## Features
- **User Management:** Add multiple users to the system.
- **Expense Splitting:** Supports both **Equal** and **Custom** splitting logic.
- **Transaction History:** View all past transactions and how they were divided.
- **Balance Summary:** Real-time calculation of who owes whom.

## Technology Stack
- **Language:** Python 3.x
- **Framework:** Flask
- **Database:** SQLite (SQLAlchemy ORM)
